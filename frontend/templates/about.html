About the Project

This final-year research prototype demonstrates an end-to-end workflow for prenatal screening risk estimation using a synthetic dataset. The pipeline includes dataset inspection, preprocessing, model training, evaluation, explainability, PDF reporting, and a Flask web interface.

The application is intentionally framed as a screening risk estimation research tool. It does not diagnose fetal conditions and must not be used independently for clinical decision-making.

  • Python ML pipeline with scikit-learn and XGBoost
  • Flask backend with SQLite history storage
  • Bootstrap 5 and Chart.js frontend
  • ReportLab PDF report generation
